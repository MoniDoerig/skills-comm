# Provenance — how this grader pack was calibrated

The pack is the **frozen output of a one-time calibration** on the benchmark subject
(ds002790 `sub-0004`, native T1w space). It is not re-derived when a submission is scored.

## Inputs

A panel of **accepted tools**, each run on the subject's T1w:

- **ANTs** (`antsBrainExtraction`)
- **HD-BET** (deep learning)
- **FSL BET** (default preset) — the grid tool that defines the reference space
- **AFNI** `3dSkullStrip` — mask taken from the skull-stripped brain and solidified onto the
  native (oblique) grid; see the note below
- **SynthStrip** (deep learning)

## Calibration steps

1. **Geometry harmonisation.** Every mask is reoriented to canonical RAS and placed on the reference
   grid. AFNI's `3dSkullStrip` writes a *header-only deoblique* (obliquity zeroed, voxel data left on
   the input grid); trusting that header and resampling displaces the brain ~11 mm, so it is read on
   the native grid instead. The grader carries the raw reference affine (`rubric.json:grid.raw_affine`)
   to detect the same case in a submission.
2. **STAPLE consensus** (Warfield et al., 2004) of the panel → per-voxel p(brain); binary consensus at
   p ≥ 0.5 (`reference/consensus_mask.nii.gz`).
3. **Zones** from the raw agreement fraction: core = unanimous, background = nobody, margin = the rest
   (`reference/consensus_zones.nii.gz`).
4. **τ** = the 95th percentile of pairwise surface disagreement *among the accepted tools*
   (`rubric.json:tau_mm`).
5. **Envelope** by **leave-one-tool-out**: hold out each tool, rebuild the consensus from the rest,
   score the held-out tool → per-metric {median = full marks, worst = pass line}
   (`rubric.json:envelope`).
6. **Focal-loss cap** = max(`SLACK` × worst held-out focal miss, floor) (`rubric.json:focal_max_cm3`).

The steps above are the full procedure. The pack is regenerated by re-running them on the panel
masks for a subject — build the STAPLE consensus and zones, derive tau and the leave-one-tool-out
envelope, then write `rubric.json` and the `reference/` NIfTIs. Rebuilding with the same panel and
subject reproduces this pack exactly; all numbers a grader needs are in `rubric.json`.

## Reference data (on OSF)

The `reference/` NIfTIs are on OSF with the other task ground truth:

- OSF project zjqey (https://osf.io/zjqey/), path `ground_truth/structural_gt/structural-brain-extraction/`
- `consensus_mask.nii.gz`, `consensus_zones.nii.gz` (native T1w space)

Fetch them before grading — see `reference/README.md` for the `osf fetch` commands. Everything else
the grader needs (tau, the envelope, the gate caps) is in `rubric.json`.

## Caveats

- **Consensus of tools is not truth.** If every accepted tool keeps a structure (e.g. the superior
  sagittal sinus), removing it is penalised. One manual expert tracing would settle it.
