# combat-harmonization

Plan, execute, and quality-check ComBat-family harmonization of multi-site neuroimaging features.

## Skills

- `combat-harmonization-strategy/` — choose the right ComBat variant for the data.
- `combat-harmonization-execution/` — submit and validate the harmonization run.
- `harmonization-qc/` — generate visual and quantitative QC for harmonized outputs.
