# registration

Perform and quality-control medical/neuroimaging image registration.

## Skills

- `registration/` — align, register, normalize, warp, resample, or spatially transform images using validated Neurodesk tools.
- `registration-qc/` — compute registration metrics and render visuals to return a structured PASS / BORDERLINE / FAIL verdict.
